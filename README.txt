TP Vertriebscockpit – modulare JavaScript-Struktur

Ordnerstruktur:
- index.html
- style.css
- logo2.png (bitte aus dem bisherigen Projekt übernehmen)
- js/
  - config.js
  - state.js
  - navigation.js
  - dashboard.js
  - customers.js
  - appointments.js
  - activities.js
  - followups.js
  - forms.js
  - maps.js
  - import.js
  - canvas.js
  - events.js
  - app.js

Wichtig:
1. Den bisherigen Projektordner zunächst sichern.
2. index.html und style.css durch die Dateien aus diesem Paket ersetzen.
3. Den kompletten Ordner js in das Projektverzeichnis kopieren.
4. logo2.png bleibt unverändert im Hauptordner.
5. Die bisherige app.js wird nicht mehr eingebunden und kann nach erfolgreichem Test archiviert werden.
6. index.html im Browser öffnen und alle bisherigen Funktionen testen.

Die Reihenfolge der Script-Dateien in index.html darf nicht beliebig geändert werden,
weil spätere Dateien Funktionen und Variablen aus früher geladenen Dateien verwenden.
